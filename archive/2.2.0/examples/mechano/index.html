    Mechanochemical Analysis¶

    Search for the optimal force application point, rupture force and the correspongding rupture product using the given reactant structure with aRST version dev.

    Contents

    • Standard analyse

    Standard analyse¶

    In the following, standard runs are demonstrated using the Cyclobutane (No.2 of Klein dataset) as an example.

    aRST input.toml --fmax ff1.csv
    This command must be executed from the command line. ff1.csv is the force field fitted force constant file coming from FFiTS You can save the terminal output by appending > record.log 2>&1 to the end of the command.

    The resulting log file will look similar to the example shown in the output tab above. In addition, the file struc.json records detailed electronic information for all structures encountered during the search, while file reaction.json records detailed reaction information.

    [geom.reactant1]
name="coord.xyz"
charge = 0
multiplicity = 1

[read.general]
gfn2opt = true
jumprefine=true
[searching_setting.general]
sp_method = "gxtb"
scan_mode = 1
exclude_elements=[1]
mb_level=1
[searching_setting.reactivity]
afo_method = "gfn2"

[searching_setting.disso]
number = 1
stretch_scale=1.5
pulling_distance='auto'

[xtb_setting]
method = "gfn2"
alpb = "ch2cl2"
scan_etemp = 1000
k = 1
