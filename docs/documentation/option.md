#Option Documentation
This page contains the documentation of all available option keywords for aRST

---

## Runtype Options

Selecting one of the specified options `[OPTION]` listed in the table below sets the program to the corresponding
runtype.

| Runtype              | `[OPTION]`      | Description                                                                                                                                    |
|----------------------|-----------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| Reaction exploration | `--explore`     | Generate product structures based on the given reactant structures.                                                                            |
| Reactivity overview  | `--afo_feature` | Generate reactivity features (AFO for the bond-forming event and MBO for the bond-breaking event) and generate a reaction prediction overview. |
| Structural alignment | `--align`       | Align two structures with low steric hindrance between the selected central atoms.                                                             |
